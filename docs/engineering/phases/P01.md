## Goal
A deterministic galaxy generator for Tiny and Evening Standard with race-aware fair starts, the core state model with save/load, a New Game screen, and a pannable, zoomable galaxy map with a system panel. All content needed for the galaxy and the species (climates, traits, races, difficulty) exists as data.

## Playable at the end
Main menu → New Game: choose Tiny or Evening Standard, difficulty, one of the four first-wave races (Swans, Pheasants, Ducks, Geese), Seat the Swans toggle, a seed string (with a "random" button) → Start → the galaxy map: stars with diffraction spikes and names, Orn at the centre, the wormhole drawn as a dashed line, the homeworld systems marked; click a star → a system panel lists planets (climate, size, minerals, special, max pop for your species). WASD / arrows / right-drag pan, wheel zooms, Home centres on your homeworld, Esc returns to the menu.

### `climates.json` rows
`{ "class": "habitable"|"hostile"|"outpost", "pop_per_size": int, "farm": int, "fish": int, "needs_flag": null|"dome_perches_1"|"crackle_shutters" }` for: gaia 5/3/2, terran 4/2/1, ocean 4/2/3, swamp 3/2/2, arid 3/1/0, tundra 2/1/2, desert 2/1/0 (habitable, `needs_flag` null); barren, inferno, toxic 1/0/0 hostile `dome_perches_1`; radiated 1/0/0 hostile `crackle_shutters`; asteroids, gas_giant outpost 0/0/0.

```gdscript
var planet_ids: Array[int] = []

var id: int; var system_id: int; var orbit: int
var climate: String; var size: String; var minerals: String; var gravity: String   # "low"|"normal"|"heavy"
var special: String = ""                   # "" = none
var colony_id: int = -1

class_name GameState extends RefCounted
var version: int = 1
var settings: GameSettings
var turn: int = 1
var next_ids: Dictionary = {}              # kind (String) -> next int id; use alloc_id(kind)

var planets: Array[Planet] = []            # dense, index == id

func to_dict() -> Dictionary

```
Later phases add fields to `GameState`; each addition updates `to_dict`/`from_dict` and bumps nothing (version bumps start after the first public build).

```gdscript
class_name Habitability   # static
static func pop_per_size(db: ContentDB, traits: Array[String], climate: String, flags: Array[String]) -> int
	# GDD §3.4 order for pop: base climates.pop_per_size -> trait floors -> trait adds -> trait caps.
	# Hostile access: if climates.needs_flag is set and that flag is not in `flags` and the species is not tolerant -> 0.
	# Outpost bodies -> 0.

class_name Seating        # static
static func resolve(settings: GameSettings, db: ContentDB) -> Array[String]
	# empire 0 = settings.player_race. Evening Standard (GDD §2.1): AI seats = swans (if seat_swans), one early-war
	# (geese|pheasants), one schemer (crows|ducks), choosing the first PLAYABLE candidate in that listed order that is not
	# already seated; refill any missing seat from the remaining playable races in races.json id order.
	# Tiny: AI seats = swans (if seat_swans) and one early-war, refilled the same way.

class_name GalaxyGenerator  # static
static func generate(settings: GameSettings, db: ContentDB) -> GameState

class_name Serializer       # static; bytes only, no file IO
static func to_bytes(gs: GameState, summary: Dictionary) -> PackedByteArray    # gzip(JSON envelope)
static func from_bytes(bytes: PackedByteArray) -> Dictionary                    # {"ok": bool, "error": String, "state": GameState, "envelope": Dictionary}
```
Envelope: `{ "format": "foulfowl-save", "version": 1, "game_version": "0.1.0", "created_unix": 0, "turn": int, "seed_string": String, "summary": {...}, "state": gs.to_dict() }`. Compress with `PackedByteArray.compress(FileAccess.COMPRESSION_GZIP)`, decompress with `decompress_dynamic(-1, FileAccess.COMPRESSION_GZIP)`. `Migrations.migrate(env: Dictionary) -> Dictionary` is the identity for version 1 and returns an error for unknown versions.

## Generation algorithm (`GalaxyGenerator.generate`; one stream `Rng.keyed(seed, 0, Rng.GALAXY, 0, 0)` consumed in exactly this order; a second stream `Rng.keyed(seed, 0, Rng.NAMES, 0, 0)` for names)
1. `settings.seats = Seating.resolve(settings, db)`; `n = preset.empires`.
2. **Positions**: `W = width_pc*10`, `H = height_pc*10`, `sep = gen.min_sep_dpc`. Up to `darts_per_star * stars` darts: `x = range_i(margin, W - margin)`, `y = range_i(margin, H - margin)`; accept when `IntMath.dist` to every accepted point ≥ `sep`; stop at `stars`. Short: `sep = pct(sep, relax_pct)`, clear, retry (≤ `max_relax`). Ids in acceptance order. Store `gen_min_sep = sep`.
3. **Star types**: weighted pick per star in id order.
4. **Orn**: the star nearest `(W/2, H/2)` (ties: lower id); `is_orn = true`, type `yellow`.
5. **Planets** per star in id order: `orbits = range_i(orbits_min, orbits_max)`; per orbit: `chance_pct(outpost_body_pct)` → asteroids or gas_giant (`chance_pct(50)`); else if the habitable map is non-empty and `chance_pct(habitable_pct)` → weighted habitable climate; else weighted hostile climate. Size weighted (outpost bodies: medium), minerals weighted from the star, gravity via `gravity_for`, special: if not an outpost body and `range_i(1, special_one_in) == 1` → weighted special. Orn: replace orbit 0 with gaia/huge/ultra_rich/no special.
6. **Homeworlds**: candidates = non-Orn stars ≥ `homeworld_min_orn_dpc` from Orn. First = farthest from Orn; next = maximises the minimum distance to those chosen (ties: lower id). If fewer than `n` candidates, use every non-Orn star and `SimLog.warn("homeworld_fallback")`.
7. **Seat → homeworld**: shuffle the chosen homeworld list with the GALAXY stream; empire `i` gets list[i]; set `home_of`.
8. **Homeworld planet**: orbit 0 of that star becomes the race's homeworld climate/size/minerals, no special, gravity normal.
9. **Fair start** (empires in id order; a planet touched here is *locked* and never touched again): within `fair_radius_dpc` of the homeworld star, excluding Orn, other homeworld stars and the homeworld planet itself: count unlocked planets `is_good_for` the race. More than `fair_good` → convert the farthest extras (ties: higher planet id first) to `barren`; fewer → convert the nearest unlocked non-outpost planets (by distance, then planet id) to `best_climate`, size `medium`. Lock the `fair_good` planets. Then ensure ≥ `fair_outposts` outpost body in range, converting the nearest unlocked planet if needed (lock it).
10. **Wormhole** (`wormhole_pairs` > 0): candidate pairs (a < b) of non-Orn, non-homeworld stars with distance ≥ `pct(W, wormhole_min_width_pct)`, sorted by (a, b); pick `range_i(0, count-1)`; link both ways. None qualify → `SimLog.warn("no_wormhole")`.
11. **Monsters**: `{"kind":"guardian","system_id": orn}`; `leviathans` richest non-Orn non-homeworld stars ≥ `leviathan_min_home_dpc` from every homeworld (richness = Σ over planets of mineral rank + size value; ties lower id).
12. **Names**: NAMES stream shuffles `1..64`; star `i` takes element `i`; Orn's `name_id = -2`.

## UI and rendering
- `NewGameScreen`: preset radio (Tiny / Evening Standard with `menu.preset.<id>.name` + `.sub`), difficulty option button (`difficulty.<id>.name`, tooltip `.tip`), race list (playable races only: colour swatch, `race.<id>.name`, `race.<id>.pitch`), Seat the Swans checkbox (`menu.toggle.seat_swans`, tooltip `.tip`), seed `LineEdit` + Random button (random seed string from `Time.get_ticks_usec()`: UI code, allowed), Start. Start → `Session.start_galaxy(settings)` → router `galaxy`.
- `GalaxyScreen`: hosts the map (in `World`) and a right-side `SystemPanel` (fixed width 340 px). Esc → main menu.
- `GalaxyMapView` (`Node2D`, child of `World`): 1 pc = 40 px (`dpc * 4`). `StarfieldLayer` draws ~600 faint dots once (positions from a local `Rng.new(7)`; render code may use Rng). `StarLayer._draw()`: per star a soft glow (three filled circles of falling alpha: planets and stars are round; this is not an effect ring), four diffraction spikes (two crossed lines, tapered alpha), colour by type, the name (`draw_string` with the theme font) under it, a small empire glyph under homeworlds (`EmpireStyle.draw_glyph(canvas, glyph, pos, size, color)`), Orn in gold, wormhole as a dashed line. Redraw only on change (`queue_redraw` on selection/zoom).
- `MapCamera` (`Camera2D`): zoom 0.35-3.0 at the cursor; WASD/arrows pan; right or middle drag pan; Home centres on the player's homeworld; clamped to the map bounds + 200 px. Mouse-only: `GalaxyScreen` also shows small on-screen buttons zoom in / zoom out / centre on home, and a Menu button.
- Performance: `StarLayer` and `StarfieldLayer` redraw only when the star set, selection or zoom bucket changes, never per frame; star names are drawn only when zoom ≥ 0.6.
- Click picking: the nearest star within 24 screen px → `SystemPanel.show_system(id)`: name, star type, then one row per planet: orbit, `climate.<id>.name`, size, minerals, special name, and "max pop N" for the player's species (from `Habitability.max_pop`, flags empty). Fixed column widths.

## Traps
- PLAN §7. Especially: JSON keys in `to_dict` are Strings; convert back with `int()`; `Array[StarSystem]` from JSON needs a loop that calls `StarSystem.from_dict` and `append`.
