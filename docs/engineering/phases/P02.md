## Goal
Empires with species and traits own colonies; colonies grow, eat from a pooled food store, assign jobs by preset, produce into a queue with overflow and fillers, build buildings, pay upkeep and administration, and go on Strike when broke. A sliced turn pipeline runs it; the player changes it only through validated commands that can be undone and redone by restore + replay; games autosave and load. A headless scenario runner exists from now on.

## Playable at the end
New Game → map with your homeworld coloured → top bar (turn, credits and net, food balance, End Turn, Undo, Redo) → click your homeworld → Colony panel: pop/max, jobs with +/- and Lock, preset dropdown, yields with breakdown, buildings, a production queue (add, remove, move, repeat, buy) → End Turn (the overlay records the worst frame) → Turn Summary lists what happened with Go-to buttons → Continue on the main menu loads the latest autosave. AI empires exist and run governors (no AI decisions yet).

| Kind | Fields | Refuses (key) when | Applies |
|---|---|---|---|
| `set_preset` | colony_id, preset | not owner (`refuse.not_owner`), unknown colony/preset (`refuse.unknown`) | sets preset; unlocks jobs unless preset is manual |

| `queue_remove` | colony_id, index | not owner; index out of range | removes; if index 0, `progress_pp` stays (carries to the new head) |
| `queue_move` | colony_id, from, to | not owner; out of range | moves |
| `queue_set_repeat` | colony_id, index, count | not owner; out of range; count 0 or < -1 | sets count |
| `buy` | colony_id | not owner; empty queue; filler head (`refuse.cannot_buy_filler`); treasury < price (`refuse.cannot_afford`); already requested | sets `buy_requested` on the head |

Rush price (`Production.buy_price(db, gs, colony_id) -> int`): `remaining x rush_mult_pct / 100`, doubled again (`rush_zero_progress_mult_pct`) when `progress_pp == 0`.

### Turn pipeline
```gdscript
class_name TurnProcessor extends RefCounted
enum Status { RUNNING, NEEDS_INPUT, DONE }
func _init(gs: GameState, db: ContentDB) -> void
func run_next_substep() -> int          # one bounded call of the current step
func run_all() -> void                  # loops to DONE (answers NEEDS_INPUT with standing plans, from P04)
func progress_pct() -> int
var report: TurnReport

class_name TurnStep extends RefCounted   # subclasses: begin(ctx) builds a work list (sorted ids); next(ctx) processes up to `slice_items` items, returns true when done
func id() -> StringName
func begin(ctx: TurnContext) -> void
func next(ctx: TurnContext) -> bool
```
Step order now: `production`, `population`, `finance`, `governor`, `finalize` (later phases insert theirs at the ARCHITECTURE §7.1 positions; keep the list in `TurnProcessor.STEP_ORDER` as StringNames with a registry of step scripts). In debug builds and tests, `Invariants.check` runs after each step and every violation is reported through `SimLog.warn("INVARIANT", ...)`.

- **production** (per colony): PP = `Economy.colony_output().industry`; if `buy_requested` and treasury ≥ price at this moment → pay, complete the head; else spend PP on the head: completion when `progress_pp ≥ cost`; overflow carries in full to the next item, repeatedly; `count` decrements (−1 never); a building completion adds it to `buildings` (notice `notify.building_done` functional key); fillers: trade goods add `floor(PP / trade_goods_pp_per_credit)` credits (recorded for finance), housing adds `PP x housing_milli_per_pp` milli pop (capped at max). Building cost = `pct(pp, 100 + building_cost_pct)`.
- **population**: empire food: produced − eaten; deficit → import at `food_import_credits_per_food` per food from treasury (never below 0); unpaid food → the most populous colony (ties lowest id) loses `ceil_div(unpaid, starve_food_per_pop)` pop units (`notify.starvation`). Then growth per colony (GDD §5.2): `growth = (P x (M − P) / M x growth_k_pct / 100 + growth_flat_milli) x (100 + growth_pct) / 100` with `IntMath`, only when `P < M` and not blockaded; `P = min(P + growth, M)`.
- **finance**: income = Σ taxes + Σ credits_flat + trade goods + `floor(surplus_food / food_sale_food_per_credit)`; expenses = Σ building upkeep + administration (`admin_cost` per colony beyond the capital, `admin_cost_high` for each colony beyond the `admin_high_after`th) (+ ship upkeep from P03); `treasury += income − expenses`; if negative → `treasury = 0`, `strike_next_turn = true` (`notify.strike`), else false. The Strike applies as `industry_pct` `strike_industry_pct` in the next turn's Modifiers.
- **governor**: `Governor.assign_jobs`, then `fill_queues` for every empire.
- **finalize**: drop expired `TimedMod`s, `turn += 1`, store the report.

**Job assignment** (`Governor.assign_jobs`, deterministic): (1) for each unlocked colony, ascending id: farmers = all pop if `farm_first`, else 0; (2) while empire food < need: add one farmer to the unlocked colony that still has a non-farmer and the highest food per farmer (ties, orchestrator ruling 2026-10-06: (a) `farm_first` presets first; (b) then colonies whose preset is NOT capital; (c) then the colony with the MOST remaining non-farmers; (d) then lowest id for determinism); stop when no colony can add; (3) per unlocked colony, the rest R splits `workers = ceil_div(R x w, w + s)`, `scientists = R − workers`. Locked colonies keep their jobs; when their pop changes, add/remove workers first, then scientists, then farmers.
