## Goal
Thirty-six research nodes (six fields x six tiers): each completion grants the core and one chosen option (Creative both, One-Note never the sibling), every option has an effect the player can feel, unchosen early options reopen two tiers later at 150%, Hyper-Preened forks are final. Techs unlock parts, hulls, buildings, stat effects and rule flags. Ships refit at yards, designs miniaturise, the AI researches and redesigns.

## Playable at the end
The Research screen shows the six fields as columns and tiers as rows; pick a node and its option, queue more, watch RP flow from the top bar; new parts appear in the designer, auto-designs upgrade queued ships, old hulls refit at a Yard for the price difference. The AI keeps pace.

## Model and rules (public API)
```gdscript
class_name TechState extends RefCounted
var known: Array[String] = ["start"]          # tech ids (cores and options)
var completed_nodes: Dictionary = {}          # node id -> chosen "a"|"b"|"both"
var project: Dictionary = {}                  # {"type": "node", "node": id, "option": "a"|"b"} or {"type": "sibling", "tech": id}; {} = none
var progress_rp: int = 0
var queue: Array[Dictionary] = []             # same shape as project
var last_received_turn: int = -100            # transfer limit (P08)
func knows(tech_id: String) -> bool
func highest_tier(field: String) -> int       # highest completed tier in the field (0 = none)

class_name Research   # static
static func cost(db, gs, empire_id: int, project: Dictionary) -> int
	# node: research_cost_k x tier^2 x (100 + creative_tier_cost_pct if creative)/100; sibling: x sibling_cost_pct/100
static func can_start(db, gs, empire_id, project) -> String     # "" or refuse key (table below)
static func complete(db, gs, empire_id, project) -> void         # grants techs; Creative grants both options
static func available_nodes(db, gs, empire_id) -> Array[String]  # next tier of each field
static func sibling_state(db, gs, empire_id, tech_id) -> String  # "known" | "locked_until_t<N>" | "available" | "final" | "never" (One-Note)
static func receive(db, gs, empire_id, tech_id, source: String) -> String   # trade/theft/capture/cache/loot path: grants a single tech; Exodus keys refuse (`refuse.exodus_locked`) unless source is "research"
class_name TechEffects  # static
static func effects_for(db, gs, empire_id) -> Array             # all effect dicts from known techs (fed to Modifiers)
static func has_flag(db, gs, empire_id, flag: String) -> bool
static func unlocked(db, gs, empire_id, kind: String, id: String) -> bool   # parts/hulls/buildings: "start" or a known tech unlocks it
```
**Rules** (`can_start` refusal keys): node not the next tier in its field (`refuse.research_prereq`); option not "a"/"b" (`refuse.unknown`); node already completed (`refuse.research_done`); **sibling** of a completed node: the empire is One-Note (`refuse.research_one_note`); the node's tier ≥ `final_fork_min_tier` (`refuse.research_final`, copy `ui.research.fork_final`); the field's `highest_tier < node tier + sibling_wait_tiers` (`refuse.research_fork_locked`, copy `ui.research.fork_locked`); sibling already known. Creative empires never need siblings (both options come with the node). `artifact_homeworld`: at start, two T1 nodes chosen with `Rng.keyed(seed, 0, Rng.RESEARCH, empire_id)` are completed with option a.

**StepResearch** (ARCHITECTURE step 6): RP = Σ colonies' research; add to `progress_rp`; while progress ≥ cost of the project: complete it, subtract, pull the next queue entry (skipping entries that became invalid), overflow carries; no project and no queue → RP banks into `progress_rp` (shown as "unassigned"). Completion notice `notify.tech_done` (BIBLE MB§2 #34). On completion, run `AiDesign`/auto-upgrade for the empire if "upgrade queued designs" is on.

**Refit** (`CmdRefit`: ship_ids, design_id): ships in one fleet at a system with an own colony that `counts_as_yard`; target design same hull, not obsolete, legal; cost = max(0, new PP − old PP) per ship, paid from the treasury at once (refuse `refuse.cannot_afford`); `refit_until = turn + refit_turns` (the ship cannot move or fight until then; it is skipped in battle building); design switches at completion. Refusals: not at a yard (`refuse.refit_no_yard`), hull mismatch (`refuse.refit_hull`).

**Upgrade queued designs** (`Empire.upgrade_queued` default true; `CmdUpgradeQueuedDesigns` toggles): when a new design is saved with `replaces` = an older design id of the same role, every queue item of the old design switches to the new one (progress kept); the old design becomes obsolete.

**Miniaturisation** (`DesignRules.mini_pct`): `max(miniaturize_floor_pct, 100 − miniaturize_step_pct x (highest_tier(part field) − part tier))`, where a part's tier is the tier of the tech that unlocks it (start parts tier 0).

**Loot and capture**: Guardian kill → `guardian_loot_techs` random unknown techs (core of a node not completed, or a missing option) from computers/construction/force_fields/planetology with tier ≤ `highest_tier(field) + 1`, keyed `Rng.LOOT`, never an Exodus key or a weapons tech; Orn-Plating becomes legal for that empire. Invasion win → `capture_tech_pct` keyed chance of one tech the victim knows and the attacker does not (not an Exodus key) via `Research.receive(..., "capture")`. Old Nest special → the first colony founded there grants one unknown T1/T2 tech (keyed).

**Roost Gate**: own colonies with `roost_gate` are gate systems; a move between two own gate systems takes 1 turn (like the wormhole) and ignores range.

**AI** (`AiResearch` in `plan_economy`): keep the project + 2 queued; score each available node option by Σ over its tags of personality weight (econ ← research/expansion avg, military ← military, expansion ← expansion, defense ← defense, spy ← spy) + needs (hostile-only targets in range → dome_perches/crackle_shutters +5; enemy shield ≥ 4 seen → beak/between_the_ribs +4; enemy Horizon seen → second_sun +4; capped range → propulsion cores +3); ties lowest node id then option a. Exodus pursuit (P08) adds weight to the two key cores. `AiDesign`: after any completion, auto-design every role whose best design changed and save it with `replaces`.
