## Rules
- **Specialisation** (`set_specialization` colony_id, spec id or ""): REFUSE pop < `spec_min_pop_units` (`refuse.spec_pop`), Yard without `the_yard` (`refuse.spec_needs_yard`), same spec; ALLOW otherwise. A change while one was set starts **Retooling** until `turn + retool_turns`: the new spec's positive effects are halved (floor toward zero), its negative effects apply in full (Modifiers lines `ui.mod.retooling`). Setting "" removes effects at once with no retool. Heron/Albatross/Titan buildable only at Yard-specialised colonies and the capital; refits likewise.
- **Supply lines** (`SupplyLines.pct(db, gs, colony_id) -> int`): distance d from the empire's Grand Nest colony (if none: from its largest colony); `0` if `d ≤ supply_free_dpc`, else `max(supply_max_pct, supply_step_pct x ceil_div(d − supply_free_dpc, supply_step_dpc))`. Applied as a Modifiers line to `industry_pct`, `research_pct`, `taxes_pct` only. **Never to food.**
- **Prospect** (`Prospect.line(db, gs, empire_id, planet_id) -> Dictionary`): `{ "food", "credits", "pp" }` at pop 3 and at max pop for the empire's species, under frontier jobs, after supply lines, admin cost and building upkeep of an empty colony. Shown on the Nest Ship colonise action, on suggested targets and on planet hover.
- **Governor log**: every `governor_log_every` turns the summary gets a "While You Were Away" entry (`summary.digest.title/body`, BIBLE MB§2 #38) listing per colony the governor-added items and preset job changes since the last log. Governors never trade tech, declare war or cancel a victory project (assert by test: no governor path issues those commands).
- **Templates**: `apply_template` (colony_id, template_id) appends its items (skipping invalid ones with the refusal recorded in the result notice); `save_template` (name, from colony queue). **Bulk** (`bulk_colonies`: colony_ids + one action of set_preset / set_specialization / apply_template): validates every sub-action first; refuses entirely if any is refused (`refuse.bulk_partial` listing the first refusal), else applies all.
- **Rally points** (`set_rally`: colony_id, system_id): new ships from that yard join an idle fleet heading to the rally system.
- **Next decision** (`NextDecision.list(gs, db, empire_id) -> Array[Dictionary]` `{kind, id, key}`), in this order: pending proposals/capitulations; no research project; colonies with an empty queue and `auto` off; idle Nest/Stake ships with a valid target in range; idle armed fleets outside a colony system; Battle Orders setting reminders never. `N` cycles them; a "Next" button in the top bar does the same (mouse-only).
- **Victory clock** (`VictoryClock.doors(db, gs, empire_id) -> Array[Dictionary]`): per door, progress numbers and a linear ETA from the last 10 turns' rate: Conquest (rivals left), Called Game (turns to cap, current rank); Grand Roost and Exodus rows are added in P08 (keep the API open: each door is a registered function).

## UI
- `ColonyPanel`: specialisation dropdown (refusals as disabled tooltips), retooling countdown, supply-line line in breakdowns, template apply/save, rally button (then click a star).
- `ColoniesListScreen`: checkboxes per row + "select all", bulk action bar (preset, specialisation, template) with a confirmation showing how many colonies change; columns add Spec and Supply.
- `TurnSummaryScreen`: sections Research, Production (with why-queued tooltips), Colonies, Military (battles, autopsy line, Replay), Diplomacy, Events, PNN, Governor log; decisions pinned at the top; every row has Go-to.
- Overlays (buttons + keys 1-5): fuel range, minerals, habitability for your species, threat (visible enemy fleet power), ownership. All as shaded cells or filled icons, no rings.
- `HotkeyTable`: the single table of GDD §15 keys (Enter/Space end turn; Esc; G galaxy, C colonies, R research, D diplomacy, F fleets, P designer, U summary, T victory clock; N next; Tab colonies; Home capital; WASD; 1-5; Ctrl+Z/Y; Q/L). Every one has an on-screen button equivalent. No F-keys, no Ctrl+S/W/T/N/R.
- `VictoryClockPanel`: one row per door per known empire (`ui.victory_clock.*`, GROK1 B6; `.eta` GAP).
