## Soak gate (GDD §17.2, revision 4)
- `balanced280`: Evening Standard, Flighted, Seat the Swans off; each of the 70 four-race subsets of the 8 races used 4 times (280 games; every race in 140, every pair 60); seeds `B0..B279`; `--procs 8` foreground subprocesses.
- Report per race: wins / 140, **point estimate**, 95% Wilson interval. Gate: point estimate in band (Swans 35-45%, others 15-35%); point outside but interval overlapping the band → **INCONCLUSIVE**: rerun 280 fresh games (`C0..C279`) and judge the pooled n = 280 per race on its point estimate; point outside with the interval entirely outside → FAIL.
- Also gated (point estimates): games ending before the cap ≥ 90%; victory mix Conquest ≥ 30%, Grand Roost 10-35%, Exodus ≥ 5%, Called Game ≤ 10%; Grand Roost wins before T120 in ≤ 1/3 of games with Ducks; Coalition trips in ≥ 50% of games; Coalition bite ≥ 50% of trips; median end turn 120-180; hard zeros (starving AI > 10 turns, `AI_REJECT`, invariant violations, script errors).
- Reported without a gate: the coalition report rows, the colony payback report, per-turn timings (native T150 End Turn ≤ 300 ms target), `swans40` (Seat the Swans on, 40 games).
- `--probes`: P1a, P1b, P2, P3, P4, P5, P7, P10 must PASS; P8 and P9 printed.

## Tuning protocol (orchestrator-directed)
1. Run `balanced280` + probes; paste the report into the PR.
2. The orchestrator chooses data changes (the builder may propose them under *Needs*, never apply design changes). Each applied change gets a `TUNING_LOG.md` line.
3. Only numbers in `data/*.json` change (`balance.json`, content rows, `creative_tier_cost_pct`, coalition and council keys, personalities). No rule code changes; if a rule is wrong, stop and report it as a Blocker.
4. Re-run until PASS (or INCONCLUSIVE → pooled PASS). Each full run is ~1 hour on 8 processes: run it in the foreground with a long timeout, never detached.

## Playtest kit (`PLAYTEST_KIT.md`)
Instructions for 5 recorded browser playtests (≥ 2 by 4X veterans), Evening Standard, Flighted: how to record, the overlay CSV, and one sheet per test with the H1-H10 measurements and pass rules from GDD §17.4 (wall clock, decision time per turn band, settling postponement, colony decisions after T40, Battle Orders changes, AI threat, Swans hunted, ending door, web perf, unprompted screenshot).

- The pooled rerun uses fresh seeds; never re-run the same seeds hoping for a different outcome (they are deterministic).
